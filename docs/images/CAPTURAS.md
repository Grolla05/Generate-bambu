# Capturas da demonstração

O que falta capturar para a seção de demonstração dos dois READMEs. Salve nesta pasta
com estes nomes e volte a seção com as imagens (o histórico do git tem o layout de
`<table>` que estava lá antes).

| Arquivo | Cena | Dica |
|---|---|---|
| `demo.gif` | fluxo inteiro: pedido → peça no Fusion → OK → fatiado no Bambu Studio | 15–30 s, largura 1200 px, corte as esperas |
| `01-pedido.png` | a conversa com o agente pedindo a peça | um pedido curto, como o do chaveiro do README |
| `02-fusion-modelagem.png` | a peça paramétrica aberta no Fusion, com a árvore de corpos `slotN_` visível | vista `iso-top-right` |
| `05-bambu-studio-cores.png` | o fatiado no Bambu Studio, com as cores por slot | pré-visualização, mostrando tempo e gramas |
| `peca-impressa.jpg` | a peça impressa na A1 | fundo neutro, luz lateral |

Sugestão: use `modelos/chaveiro.py` com os parâmetros padrão. Ele já foi conferido no
Fusion, e o mesmo arquivo serve para todas as cenas.

Não publique captura com caminho pessoal, nome de cliente ou access code na tela.
